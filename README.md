# SwimMMTimeKeeperCards
A python utility to generate timekeeper cards from Swim Meet Manager files

## How to use
To generate the time keeper cards, after a meet is set up in Meet Manager, click on Reports, and then select Lane/Timer sheets.
In the screen that follows, click Select All, and then Create Report.
Click on the Export Report button, and choose Separated Values (CSV)

<img width="923" height="627" alt="image" src="https://github.com/user-attachments/assets/67f18cd1-96cd-420f-9924-efac1fbd55cb" />

<img width="701" height="456" alt="image" src="https://github.com/user-attachments/assets/89aca988-78cb-48c9-b85d-e653d66ec782" />

Press OK on the next screen

<img width="463" height="327" alt="image" src="https://github.com/user-attachments/assets/cb76bea4-56cc-4e79-86cf-cf09d2db9445" />


Give the file an understandable filename (e.g., 200mChamps2025), and save it in
`Documents>TimeKeepers`

Open File Explorer on the system, and go to the Folder `Documents>TimeKeepers`

Double click on the TimeKeeper Cards icon on the desktop:

<img width="759" height="663" alt="image" src="https://github.com/user-attachments/assets/99b62286-9857-4ae9-b308-ceac6c042caa" />


Select `OK` in the prompt that comes up

<img width="524" height="228" alt="image" src="https://github.com/user-attachments/assets/3733a9d7-3a9f-4199-895e-f660ef15e33b" />


Pick the name of the file that you’ve just created in the prompt that comes up.

If you navigate to `Documents>TimeKeepers in the File Explorer, you’ll now see a pdf file with the
same name, which contains the Time Keeper slips.
